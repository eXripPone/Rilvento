# Перед подачей

1. Вставить название «Rilvento — проверяемое AML-досье».
2. Вставить description.txt: 884 символа с пробелами, без заголовка и кавычек.
3. Загрузить папку проекта на GitHub и вставить реальный URL.
4. Открыть PPTX, заполнить данные автора и участие в других программах на слайде 14. После изменений сохранить собственную PDF-копию. Если сведения об участии не относятся к проекту, указать достоверное «Не участвовал» только после проверки.
5. Прикрепить PDF презентации. PPTX — редактируемый исходник, загружать оба необязательно.
6. Проверить личные поля, допустимость участия, согласия и отправить форму самостоятельно.

Не прикреплять архив репозитория вместо презентации. Не публиковать ключи, реальные клиентские документы или локальную БД. Финансовые суммы являются сценарными допущениями.
