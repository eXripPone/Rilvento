# Риски

Дата: 15.10.2026. Итоговый реестр; доказательства и остаточный риск — в viability.md, правовые источники и статусы — в analysis.md. Технические меры в демо не закрывают коммерческие и юридические риски.

| ID | Риск | Статус |
|---|---|---|
| R01 | Провайдер расширит существующие расследования до досье | существенный |
| R02 | API/лицензия запретят хранение, переработку или экспорт | неизвестно |
| R03 | Рынок мал, продажи медленны, спрос не проверен | существенный |
| R04 | Ошибочная интерпретация графа как доказательства дохода | существенный |
| R05 | Персональные данные, внешний AI и раскрытие мер клиенту | требует юриста |
| R06 | Демо-роли и локальный журнал примут за защиту промышленной системы | явно ограничить |
| R07 | Единственный разработчик без заявленных AML-эксперта и юриста | привлечь экспертов до реальных процессов |
| R08 | Общие даты из разъяснений примут за проверку всех норм закона | полный официальный текст и применимость ещё сверить |
| R09 | SQLite-схему сочтут уже проверенной на PostgreSQL | перенос и миграции не проверены |
| R10 | Автоматизированное время действий выдадут за репетицию выступления | 60 секунд без речи; пяти минутный сценарий отдельно |

Остановка коммерческой разработки: недоступны права на данные, нет дополнительной ценности после сравнения, нет готовности платить, неприемлемы обработка данных или фактическая экономика. Для синтетического исследовательского демо препятствия не выявлены. Ни один из пяти критериев жизнеспособности не считается пройденным.
