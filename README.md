# Rilvento

Проверяемое досье по происхождению средств для AML-специалиста.

Идея для трека «Лучшая идея предпринимательского проекта», стипендия ФКН ВШЭ «Молодой предприниматель» 2026. AML означает противодействие отмыванию денег.

Rilvento связывает данные провайдера, граф и документы клиента с конкретными утверждениями заключения. Движение криптовалюты и экономическое происхождение средств рассматриваются отдельно. Граф не доказывает законность дохода.

## Статус
Исследовательский прототип на синтетических данных. Интеграции имитированы, внешняя языковая модель не вызывается. Спрос, готовность платить, права на коммерческие API и юридическая применимость не подтверждены. Прототип не предназначен для эксплуатации и реальных решений.

## Запуск
Нужен Python 3.12, первый запуск требует интернета для зависимостей.

```sh
python demo/run.py
```

Открыть http://127.0.0.1:8765 и http://127.0.0.1:8765/docs. Весь граф и документация отдаются локально. Остановка: Ctrl+C.

## Материалы
- application/application.md — поля заявки и что заполнить лично.
- presentation/ — PDF, редактируемая презентация и текст слайдов.
- docs/ — кабинетное исследование, ограничения и фактический отчёт о тестах.
- demo/ — FastAPI, Pydantic, SQLite/SQLAlchemy, networkx, Cytoscape.js и pytest.

## Сценарий
Очередь, карточка, граф, источники, досье, черновик запроса документов, новая версия и согласование человеком. Аналитик не может утверждать через API. Демо позволяет показать отказ провайдера и эскалацию.

## Ограничения
Любой участник локального показа может выбрать любую демо-роль. Хэш-цепочка журнала не защищает от владельца БД без независимой контрольной точки. Ссылки не гарантируют истинность источника. Документы не проверяются на подлинность. Схема PostgreSQL, Alembic, реальные провайдеры и внешние AI-адаптеры не испытаны.

Основные материалы исследования сохраняют исходное рабочее название «Основание». Для заявки выбран бренд Rilvento. Оба названия относятся к этой концепции.

Лицензия собственного кода пока не выбрана автором. Лицензии сторонних библиотек находятся в demo/static/vendor. Публикация репозитория не означает согласие на использование реальных персональных данных.
